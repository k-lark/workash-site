# 株式会社Workash コーポレートサイト

会社ホームページおよび電子公告ページの静的サイトです。GitHub Pages で公開しています。

## 公開URL

| ページ | URL |
|---|---|
| ホームページ | https://workash.jp/ |
| 電子公告 | https://workash.jp/public-notice/ |

電子公告のURLは**定款に記載した公告掲載URLと一致している必要があります**。パスを変更する場合は定款との整合を必ず確認してください。

## ファイル構成

```
/
├── index.html              会社ホームページ
├── style.css               共通スタイル（両ページで共有）
├── public-notice/
│   └── index.html          電子公告ページ
├── CNAME                   独自ドメイン設定（workash.jp）
├── .nojekyll               Jekyll による変換を無効化
└── README.md
```

## 技術仕様

- HTML / CSS のみ。JavaScript・外部ライブラリは不使用
- 文字コード UTF-8、`lang="ja"`
- レスポンシブ対応（375px 幅まで検証済み）
- ライト／ダークテーマ対応（`prefers-color-scheme`）
- 電子公告ページは `@media print` に対応（印刷時はナビゲーション類を非表示、黒文字・白背景）
- Webフォント: Noto Sans JP / Noto Serif JP（Google Fonts）

## 更新が必要な箇所

設立登記の完了後、以下を実際の情報に更新してください。

| 箇所 | 現在の内容 | 更新内容 |
|---|---|---|
| `index.html` 会社概要「設立」 | 設立準備中 | 実際の設立年月日 |
| `public-notice/index.html`「設立年月日」 | 設立準備中（設立登記完了後に確定いたします） | 実際の設立年月日 |
| 両ページの本店所在地 | 東京都品川区 | 丁目・番地までの正式表記 |

### 公告掲載期間について

現在の掲載期間は 2026年10月10日 〜 2028年10月10日（2年間）です。

**決算公告を電子公告で行う場合、会社法940条3項により5年間の継続掲載が必要です。** 決算公告を掲載する際は掲載期間を見直してください。

## ローカルでの確認

Node.js があれば、リポジトリのルートで簡易サーバーを起動できます。

```bash
npx --yes serve .
```

電子公告ページはディレクトリインデックス（`/public-notice/`）で配信されるため、`file://` で直接開くと相対パスが解決されません。必ずサーバー経由で確認してください。

## 注意

公告内容は法定事項です。変更する際は、事前に司法書士等の専門家に確認してください。
